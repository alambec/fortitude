# Contributing

Thank you for your interest in Fortitude.

**Issues are welcome.** Report bugs, interoperability problems (a DICOM file, a viewer or a
modality that does not work with Fortitude) and feature requests as GitHub issues. Never attach
files that contain patient data: anonymize them first, or describe the problem with the attributes
involved.

**Pull requests are not accepted.** Alambec sells commercial licenses of Fortitude besides the AGPL,
which requires it to own all of the code. A pull request will be closed without review; if it shows
a good idea, it may be reimplemented from the issue it describes.

Security vulnerabilities must not be reported in public issues: see [SECURITY.md](SECURITY.md).
